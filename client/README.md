# SocialImpact

**Live Website:** https://assingment-8-abdur.vercel.app

SocialImpact is a community-driven event management platform that connects people with meaningful social activities. Users can discover upcoming events, join volunteer activities, and create initiatives to make a positive impact on their communities.

## Features

- **User Authentication:** Secure registration and login with email/password and social authentication.
- **Create Events:** Authenticated users can create community events with descriptions, categories, images, locations, and event dates.
- **Explore Upcoming Events:** Browse upcoming social events with search and category-based filtering.
- **Event Details:** View complete event information, organizer details, volunteer capacity, and schedules.
- **Join Events:** Logged-in users can join events and participate in community activities.
- **Joined Events:** Keep track of all joined events in one place.
- **Manage Events:** Event creators can update and delete their own events.
- **User Profile:** View and update profile information, including name and profile picture.
- **Dark Mode:** Enjoy a comfortable browsing experience with light and dark themes.
- **Responsive Design:** Fully responsive interface for desktop, tablet, and mobile devices.
